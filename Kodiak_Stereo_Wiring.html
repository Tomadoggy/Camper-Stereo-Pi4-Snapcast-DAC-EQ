Bass remote setup

  1. Plug the supplied cable into the amp's REMOTE port and into the knob. No switch or menu setting turns it on.
  2. The knob is a CH5 level control. It only turns the sub channel down from where the onboard CH5 gain is set.
  3. Turn the remote knob all the way up, then set the onboard CH5 gain so the pucks are at the most you'd ever want. That gain setting is now your limit.
  4. Use the dash knob from there. With the knob at max, you can't drive the 15 W pucks past what you set on the amp.
  5. Leave bass boost at 0 dB. Boost is +18 dB at 45 Hz, close to the pucks' 40 Hz Fs.

Check before power-up

  • CH5 load across the joined + and − should read 1.6–1.9 Ω. Anything under that means a short or mis-wired puck.
  • CH5 harness has 4 wires. With the amp unpowered, check that the two + wires read 0 Ω to each other, and the two − wires do too, before you join them.
  • Each CH1–4 load should read about 6–7 Ω (8 Ω nominal).
  • Put the 80 A fuse within 18 in of the bus tap. Run 8 AWG for both +12V and ground.
  • Speaker wire: 16 AWG OFC to each MC2.5B. For CH5, run 14 AWG to a terminal block near the pucks, then 16 AWG out to each puck. Remote turn-on: 18 AWG.
  • Set the CH1–4 mode switches to HPF before turning the crossover pots.

Rev B supersedes the repo README on two points: one MC2.5B per channel at 8 Ω (not 2 in parallel at 4 Ω), and RCA through two 1→3 splitters (DAC L → CH1/CH3/CH5-L, DAC R → CH2/CH4/CH5-R), not the 3× 1→2 tree.
